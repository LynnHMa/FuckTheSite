# 使用方式

## 复制Raw链接
```
https://raw.githubusercontent.com/LynnHMa/FuckTheSite/refs/heads/main/search-purify.txt
```

## 添加自定义规则
 > 确保你的浏览器有安装`AdGuard`。

前往`AdGuard设置` -> `过滤器` -> `自定义` -> `添加自定义过滤器` -> `输入Raw链接` -> `下一步`。
